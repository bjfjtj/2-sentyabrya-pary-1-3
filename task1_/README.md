# Задача 1 – Класс Cat

## Условие
Создайте класс `Cat`. Добавьте в него три свойства (атрибута):
- `breed` (порода)
- `name` (имя)
- `age` (возраст)

Создайте в программе трёх разных котов (объекта этого класса) с разными данными. Выведите в консоль информацию о каждом коте.

## Решение
Класс `Cat` определён с конструктором `__init__`, принимающим три параметра. Атрибуты сохраняются как публичные (можно сделать и приватными, но по условию это не требуется). В главной программе создаются три объекта с разными данными, информация выводится через прямой доступ к атрибутам.

## Код
```python
class Cat:
    def __init__(self, breed, name, age):
        self.breed = breed
        self.name = name
        self.age = age

# Создание трёх котов
cat1 = Cat("Сиамская", "Барсик", 3)
cat2 = Cat("Персидская", "Мурка", 5)
cat3 = Cat("Британская", "Том", 2)

# Вывод информации
print(f"Кот: {cat1.name}, порода {cat1.breed}, возраст {cat1.age} лет")
print(f"Кот: {cat2.name}, порода {cat2.breed}, возраст {cat2.age} лет")
print(f"Кот: {cat3.name}, порода {cat3.breed}, возраст {cat3.age} лет")

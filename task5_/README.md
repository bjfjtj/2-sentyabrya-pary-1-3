# Задача 5 – Базовый класс Figure (DRY)

## Условие
Создайте базовый класс `Figure`. Добавьте в него общие для всех фигур свойства:
- `coords` (кортеж координат, например, `(x, y)`)
- `width` (ширина)
- `color` (цвет)

Цель – избежать дублирования кода (принцип DRY), вынеся общие данные в родительский класс.

## Решение
Класс `Figure` содержит конструктор, инициализирующий общие атрибуты. Этот класс будет использоваться как основа для наследования в следующих задачах. Пока что просто создаём объект `Figure` для демонстрации.

## Код
```python
class Figure:
    def __init__(self, coords=(0, 0), width=1, color="black"):
        self.coords = coords
        self.width = width
        self.color = color

    def display(self):
        print(f"Фигура: координаты {self.coords}, ширина {self.width}, цвет {self.color}")

# Проверка
fig = Figure((5, 3), 2, "red")
fig.display()

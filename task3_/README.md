# Задача 3 – Класс Car с инкапсуляцией

## Условие
Создайте класс `Car`. Внутри него создайте **скрытый** атрибут `_engine_temperature` (температура двигателя, по умолчанию 20). Сделайте публичные методы:
- `start_engine()` – увеличивает температуру до 90 и выводит «Двигатель прогрет»;
- `drive()` – проверяет, что температура >= 90, и выводит «Поехали!» (иначе выводит сообщение о необходимости прогрева).

Попробуйте обратиться к `_engine_temperature` напрямую извне и вызовите `drive()` без прогрева. Убедитесь, что логика защищена.

## Решение
Атрибут `_engine_temperature` объявлен с одним подчёркиванием (по соглашению – защищённый). Это не строгая приватность, но в Python принято считать такие атрибуты внутренними. Прямой доступ к нему извне возможен, но метод `drive()` проверяет значение и не позволяет ехать без прогрева.

## Код
```python
class Car:
    def __init__(self):
        self._engine_temperature = 20

    def start_engine(self):
        self._engine_temperature = 90
        print("Двигатель прогрет")

    def drive(self):
        if self._engine_temperature >= 90:
            print("Поехали!")
        else:
            print("Сначала прогрейте двигатель!")

# Создаём машину
my_car = Car()

# Попытка поехать без прогрева
my_car.drive()  # Сначала прогрейте двигатель!

# Прямой доступ к скрытому атрибуту (не рекомендуется)
print(f"Температура напрямую: {my_car._engine_temperature}")

# Прогрев
my_car.start_engine()
my_car.drive()  # Поехали!
